核心知识点速查

整本记录里最值得反复看的技术要点

🎯 关键洞察 01

低切的意义：人声切 80、Bass 切 30–100、Keyboard / 吉他切 82 —— 这些都不是它们的主要频段，清掉是为了不抢 Bass 和底鼓的清晰度，从而更有律动。

🎯 关键洞察 02

压缩看瞬态：有瞬态（如 rap、鼓）→ attack 20ms+、release 60–80ms，别盖住下一个音头；无瞬态（情歌旋律、铺底）→ attack <10ms、release 200ms+，为求平滑。

🎯 关键洞察 03

元素拆分：打击乐 = drums + drum pad；和声 = vocal + bass + keyboard。混音时先让 Bass + 打击乐 组合，再和和声组合 —— Bass 是粘合剂。

🎯 关键洞察 04

Gate 用 Key Frequency：给 Tom 压 Gate 时设置"基础频率"，只有在这个频率才会打开 Gate 让声音出去，避免误开。

🎯 关键洞察 05

混响组合：人声通常 plate + hall。plate（板式）pre-dly 0、decay ≈1s、首次反射开中等 → 给宽度；hall（大厅）decay 翻倍 2s+、通常关首次反射 → 给空间延伸。

🎯 关键洞察 06

弦乐压缩：ratio <1:2.5（压得少）、gain reduction <6dB、attack 快 <10ms、release 慢 ≈200ms。

🎯 关键洞察 07

EQ 前置原则："在调 EQ 之前，就把麦克风摆好、或换好。" 很多问题靠 摆位 而非 EQ 解决。

🎯 关键洞察 08

现场响度：原声为主的爵士 / 民谣 90 LUFS 以下；现代电音、摇滚、大型演出 95–105（正常听感上限）。
